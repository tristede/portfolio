Comment obtenir ce token (à faire une seule fois) :
  1. Va sur github.com/settings/personal-access-tokens/new (connecte-toi si besoin).
  2. Repository access → Only select repositories → choisis portfolio.
  3. Permissions → Repository permissions → Contents → mets Read and write.
  4. Clique Generate token, copie-le, et colle-le ci-dessus.

Ce token reste uniquement dans ce navigateur (stockage local) — il n'est envoyé qu'à l'API GitHub pour enregistrer tes modifications. Ne le colle pas sur un ordinateur public ; tu peux le révoquer à tout moment depuis GitHub. Fonctionne sur autant d'appareils que tu veux : colle le même token sur chacun.
